# The Curse of the Void

Website of **The Curse of the Void**, a hardcore Hytale SMP with content creators.

Live at **https://www.cursedvoid.com** (hosted with GitHub Pages).

## Structure

- `index.html` – home page (intro animation + event description)
- `players.html` – participant grid, built from `players.json`
- `bisect.html` – BisectHosting sponsor page
- `legal.html` – legal notice (links to the Impressum), privacy policy and cookies (English / German)
- `404.html` – page shown for unknown URLs
- `players.json` – participant data (images are looked up under `Assets/Players/`)
